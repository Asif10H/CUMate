# CUMate - Premium Academic Repository for Chittagong University

CUMate is a high-fidelity, professional academic resource platform specifically designed for the students of **Chittagong University (CU)**. It serves as a centralized hub for high-quality study materials, organized by faculties, departments, and semesters.

---

## 🚀 Why CUMate? (The Problem)
University students often face significant challenges in gathering organized study materials:
- **Scattered Resources:** Notes and slides are often spread across different groups, drives, and physical copies.
- **Missing Question Banks:** Finding previous year questions for specific courses is a time-consuming task.
- **Quality Control:** Not all available notes are comprehensive or accurate.

CUMate solves these problems by providing a curated, easy-to-navigate, and premium digital repository.

---

## ✨ What CUMate Offers
- **Comprehensive Coverage:** Resources for all 8 semesters of the BBA (Accounting) program, with plans to expand to other departments.
- **Rich Content Types:**
    - 📝 **Handwritten & Digital Notes:** Detailed lecture summaries.
    - 📊 **Lecture Slides:** Official class presentations.
    - ❓ **Question Banks:** Organized previous year questions (2018–2024).
- **Premium User Experience:**
    - **Live PDF Preview:** View the first page of any document before purchasing.
    - **Advanced Filtering:** Find exactly what you need by Faculty, Department, or Semester.
    - **Responsive Design:** Seamless experience across Mobile, Tablet, and Desktop.

---

## 💰 Monetization & Income Potential
CUMate is not just a repository; it's a sustainable business model for educational content creators.

1. **Pay-As-You-Go (Single Resource):** Students can purchase specific high-value notes for a small fee (৳20–৳70).
2. **CUMate Pro (Monthly/Semester):** A subscription model for unlimited access to all resources in a specific period.
3. **Full 4-Year Access:** A premium one-time payment (৳2199) for lifetime access to the entire 4-year curriculum materials.
4. **Instant bKash Integration:** Seamless payment flow via the most popular mobile financial service in Bangladesh.

## 🛠️ Tech Stack
- **Frontend:** React.js (Vite)
- **Styling:** Tailwind CSS v4 (Modern & High Performance)
- **State Management:** React Hooks & Context
- **Routing:** React Router v7
- **Icons:** FontAwesome 6
- **Typography:** Inter (Google Fonts)

## 🔧 Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Asif10H/CUMate.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd CUMate
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Run the development server:**
   ```bash
   npm run dev
   ```
